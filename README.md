# AI Toolkit

Reusable instructions for AI coding assistants.

- [skills/](skills/) — skills for coding, reviews, APIs, databases, documentation, and commits.
- [codes/](codes/) — short commands for controlling assistant behavior, in English and Russian.
- [usecases/](usecases/) — templates for documenting user goals, workflows, business rules, and expected outcomes.

Helps define clear working rules and reuse them across projects.
